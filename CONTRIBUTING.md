# Contributing to SigGear CAD Models

Thank you for your interest in SigGear CAD model resources.

This repository provides mechanical reference resources for SigGear compact precision drive solutions, including robot joint modules, compact cycloidal reducers, 6-42mm planetary gear reducers, micro gear motors, and customized drive systems.

## Contribution Scope

Contributions may include:

* CAD model organization improvements
* Mechanical documentation improvements
* Drawing reference updates
* STEP model folder structure improvements
* Integration notes for robot joints, robot arms, quadruped robots, humanoid robots, robotic grippers, AGV / AMR systems, and compact automation equipment
* Documentation corrections or formatting improvements

## File Organization Guidelines

Please organize CAD resources by product type or application:

* Robot joint modules
* Planetary gearboxes
* Micro gear motors
* Robotic gripper drive modules
* Servo motor gearbox assemblies
* Custom compact drive solutions

Recommended file types may include:

* STEP files
* STL files
* PDF drawings
* 2D dimensional drawings
* Reference images
* Datasheets

## Important Notes

CAD models in this repository are intended for reference, layout evaluation, and early-stage integration planning.

Final production design should always confirm:

* Mounting dimensions
* Shaft interface
* Output flange interface
* Gearbox ratio
* Backlash requirement
* Load direction
* Rated torque
* Peak torque
* Operating speed
* Motor compatibility
* Environmental requirements

## Safety and Design Notice

CAD models should not be used as the only basis for production design.

Before finalizing mechanical integration, please confirm the latest drawings, dimensions, tolerance requirements, and product configuration with SigGear.
