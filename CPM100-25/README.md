## Product Overview

CPM100-25 is a compact cycloidal robotic joint module optimized for humanoid robots and industrial robotics.

## Key Parameters

| Parameter    | Value   |
| ------------ | ------- |
| Diameter     | 100 mm  |
| Thickness    | 29.5 mm |
| Rated Torque | 25 Nm   |
| Peak Torque  | 75 Nm   |
| Backlash     | 0.05°   |
