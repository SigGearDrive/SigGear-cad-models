## Product Overview

SG8021 is a high-performance planetary robotic joint module designed for humanoid robots, quadruped robots and industrial robotic systems.

The module integrates:

* Planetary Gearbox
* High Performance BLDC Motor
* Absolute Encoder
* Integrated Drive Electronics
* CAN Communication

## Key Parameters

| Parameter       | Value   |
| --------------- | ------- |
| Diameter        | 100 mm  |
| Thickness       | 42.6 mm |
| Reduction Ratio | 9.25:1  |
| Rated Torque    | 10 Nm   |
| Peak Torque     | 30 Nm   |
| Voltage         | 24-48V  |
| Weight          | 671 g   |
