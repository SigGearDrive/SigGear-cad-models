# CAD Model Usage Notes

This page provides general usage notes for SigGear CAD models, STEP files, drawings, and mechanical reference resources.

The information here is intended for engineering reference only. Final mechanical dimensions, mounting details, shaft options, tolerances, and product configurations may vary by model, customization, and project requirements.

## Before Using a CAD Model

Before using a SigGear CAD model in a mechanical design, please confirm:

* Product model
* Gearbox ratio
* Output torque requirement
* Output speed requirement
* Mounting interface
* Shaft or flange interface
* Motor compatibility
* Backlash requirement
* Load direction
* Duty cycle
* Available installation space
* Environmental requirements

## Common Integration Checks

When integrating a compact gearbox or robot joint module, engineers should check:

* Mounting hole positions
* Output shaft or flange dimensions
* Cable outlet direction
* Motor installation space
* Encoder or sensor clearance
* Bearing load direction
* Heat dissipation space
* Assembly clearance
* Maintenance access
* Mechanical stop position

## Typical Application Areas

SigGear CAD resources may support mechanical design for:

* Humanoid robot joints
* Quadruped robot actuators
* Robot arm joints
* Robotic grippers
* AGV / AMR wheel drive systems
* Micro robotics
* Medical device motion systems
* Laboratory automation
* Compact industrial automation
* Servo and brushless motor drive assemblies

CAD models should be used for reference, layout evaluation, and early-stage design planning.

For production design, please confirm the latest official drawing, datasheet, tolerance requirement, and product configuration with SigGear.
