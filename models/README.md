# SigGear CAD Model Categories

This folder is used to organize CAD model resources for SigGear compact precision drive products and robotic drive systems.

## Model Categories

CAD models may be organized into the following categories:

* Robot joint modules
* Compact cycloidal robotic joint modules
* 6-42mm planetary gear reducers
* Micro gear motors
* Robotic gripper drive modules
* Servo motor planetary gearbox assemblies
* AGV / AMR wheel drive gearbox references
* Custom compact drive solutions

## Suggested Folder Structure

```text
models/
├── robot-joint-modules/
├── planetary-gearboxes/
├── micro-gear-motors/
└── custom-drive-solutions/
```

## Typical CAD Use Cases

SigGear CAD models may be used for:

* Robot joint layout evaluation
* Humanoid robot actuator integration
* Quadruped robot leg mechanism design
* Robot arm joint packaging
* Robotic gripper drive layout
* AGV / AMR wheel drive system evaluation
* Medical device motion module planning
* Laboratory automation mechanism design
* Compact automation system integration

## Notes

CAD files are provided for reference and early integration planning.

Final dimensions, mounting details, shaft interfaces, flange options, and product configurations should be confirmed with SigGear before production design.
